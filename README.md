# excel-mapper

엑셀(.xlsx) 파일의 데이터를 읽어 데이터베이스 테이블에 매핑·저장하는 프로그램입니다.

## 개발 배경
엑셀로 관리되던 프로그램 수행 이력 데이터를 DB로 옮기는 작업을
수작업 대신 자동화하기 위해 시작했습니다.

## 주요 기능
- [x] Apache POI를 이용한 엑셀 파일 읽기
- [ ] 헤더명 기반 열 매핑 및 양식 검증
- [ ] DB 저장 (MySQL)
- [ ] 오류 행 리포트

## 기술 스택
- Java
- Apache POI 5.5.1
- Gradle
